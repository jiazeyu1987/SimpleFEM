# 波峰检测缺失问题诊断分析

## 问题描述

运行 `python -m refactor.main` 后，生成的 `peak_statistics` CSV文件中没有波峰数据。

## 根本原因分析

### 配置参数

从 `simple_fem_config.json` 中可以看到：
```json
{
  "hybrid_detection": {
    "enabled": true,    // 混合检测已启用
    ...
  },
  "roi1_peak_detection": {
    "enabled": true,    // ROI1波峰检测已启用
    ...
  }
}
```

### 代码逻辑分析

**重构代码** (`refactor/orchestrator.py` 第335-349行)：

```python
# 判断是否使用混合检测
hybrid_enabled = self._config.hybrid_detection_enabled       // true
roi1_enabled = self._config.roi1_peak_detection_enabled      // true
roi1_buffer = list(self._roi_capture.roi1_buffer)

if hybrid_enabled and roi1_enabled and len(roi1_buffer) > 0:
    # 情况1: 混合检测（ROI1数据充足）
    hybrid_green_peaks, hybrid_red_peaks, hybrid_info = ...
    green_peaks = hybrid_green_peaks
    red_peaks = hybrid_red_peaks

elif hybrid_enabled and roi1_enabled:
    # 情况2: ROI1数据不足，跳过波峰检测
    pass  # ← 问题在这里！保持空列表，等待ROI1缓冲区积累数据

else:
    # 情况3: ROI2独立检测（传统模式）
    green_peaks, red_peaks = detect_peaks(...)
```

### 问题根源

当 `hybrid_enabled=true` 和 `roi1_enabled=true` 但ROI1缓冲区为空时（`len(roi1_buffer) == 0`）：

1. **不进入情况1**：因为 `len(roi1_buffer) == 0`
2. **进入情况2**：满足 `hybrid_enabled and roi1_enabled`
3. **执行 `pass`**：跳过波峰检测，保持空列表
4. **永不进入情况3**：因为前面的 `elif` 已经匹配

**结果**：在视频开始阶段（ROI1缓冲区未满），所有帧都跳过波峰检测，导致没有波峰记录。

### 原始代码的对应逻辑

**原始代码** (`simple_roi_daemon.py` 第2298-2334行)：

```python
else:
    # 保持原有的ROI2独立检测逻辑作为后备
    if hybrid_enabled:
        logging.info(f"[传统检测] 帧{frame_index} 混合检测未启用或数据不足，使用ROI2独立检测模式")

    if hybrid_enabled and roi1_enabled:
        # 混合检测启用，但ROI1数据不足
        if frame_index % 50 == 0:
            print("[混合检测] ROI1数据不足，跳过波峰检测（不回退到ROI2波峰检测）")
        green_peaks_raw, red_peaks_raw = [], []
        green_peaks, red_peaks = [], []
        detection_mode = "hybrid_roi1_insufficient"
    else:
        # 混合检测未启用或ROI1未启用，使用ROI2独立检测
        green_peaks_raw, red_peaks_raw = detect_peaks(...)
        detection_mode = "roi2_legacy"
```

**原始代码的行为**：
- 当 `hybrid_enabled=true` 且 `roi1_enabled=true` 但ROI1数据不足时
- **也跳过检测，不回退到ROI2**
- 与重构代码逻辑一致

### 为什么export2有数据而export没有？

**可能原因**：

1. **export2（原始代码）**：
   - 可能配置不同（`hybrid_detection.enabled=false` 或 `roi1_peak_detection.enabled=false`）
   - 或者ROI1缓冲区已经积累足够数据（不是从视频开始）

2. **export（重构代码）**：
   - 使用默认配置（`hybrid_detection.enabled=true` 和 `roi1_peak_detection.enabled=true`）
   - 从视频开始处理，ROI1缓冲区一直为空
   - 永远停留在"情况2"，跳过所有检测

## 解决方案

### 方案1: 修改默认配置（推荐）

将配置文件中的混合检测或ROI1检测默认关闭：

```json
{
  "hybrid_detection": {
    "enabled": false,  // 改为 false
    ...
  }
}
```

或者

```json
{
  "roi1_peak_detection": {
    "enabled": false,  // 改为 false
    ...
  }
}
```

**优点**：
- 简单直接
- 回退到传统的ROI2独立检测模式
- 与原始代码的"情况3"逻辑一致

**缺点**：
- 失去了混合检测的优势（ROI1时机 + ROI2颜色）

### 方案2: 添加回退机制（需要代码修改）

在ROI1数据不足时，回退到ROI2独立检测：

```python
if hybrid_enabled and roi1_enabled and len(roi1_buffer) > 0:
    # 情况1: 混合检测
    ...
elif hybrid_enabled and roi1_enabled:
    # 情况2: ROI1数据不足，回退到ROI2检测
    green_peaks, red_peaks = detect_peaks(...)
    logging.info(f"帧{frame_index} ROI1数据不足，回退到ROI2独立检测")
else:
    # 情况3: ROI2独立检测
    ...
```

**优点**：
- 不会漏掉波峰
- 在ROI1数据不足时仍能检测

**缺点**：
- 需要修改代码
- 与原始代码逻辑不一致（原始代码也不回退）

### 方案3: 等待ROI1缓冲区积累（当前行为）

保持当前逻辑，等待ROI1缓冲区积累足够数据。

**优点**：
- 与原始代码完全一致
- 一旦ROI1缓冲区满，就能使用混合检测

**缺点**：
- 视频开始阶段的波峰会丢失

## 快速验证方案

### 临时修改配置

将 `simple_fem_config.json` 中的混合检测临时关闭：

```json
{
  "hybrid_detection": {
    "enabled": false
  }
}
```

然后重新运行：

```bash
python -m refactor.main
```

检查生成的 `peak_statistics` 是否有波峰数据。

**如果有波峰**：说明问题确实是混合检测+ROI1数据不足导致的
**如果还是没有波峰**：说明有其他问题（阈值、数据等）

## 结论

**最可能的原因**：
- 配置文件中 `hybrid_detection.enabled=true` 和 `roi1_peak_detection.enabled=true`
- 视频开始阶段ROI1缓冲区为空
- 代码逻辑进入"情况2: ROI1数据不足"，跳过所有波峰检测
- 导致 `peak_statistics` CSV文件中没有波峰数据

**推荐解决方案**：
1. 先关闭混合检测验证：`hybrid_detection.enabled=false`
2. 确认export2使用的配置
3. 根据实际需求选择：
   - 使用ROI2独立检测（关闭混合检测）
   - 等待ROI1缓冲区满后使用混合检测（保持当前配置）
   - 修改代码添加回退机制（需要开发）
