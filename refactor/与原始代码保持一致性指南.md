1. ✅ **配置文件**: 使用同一个 `simple_fem_config.json`

### 配置文件影响分析

**当前配置（simple_fem_config.json）**:
```json
{
  "hybrid_detection": {
    "enabled": true
  },
  "roi1_peak_detection": {
    "enabled": true
  }
}
```

**执行路径（原始代码和重构代码完全一致）**:

```
IF hybrid_enabled=true AND roi1_enabled=true THEN
    IF len(roi1_buffer) > 0 THEN
        → 情况1: 混合检测
    ELSE
        → 情况2: ROI1数据不足，跳过检测
    END IF
ELSE
    → 情况3: ROI2独立检测
END IF
```

**问题所在**:
- 在视频开始阶段（0-99帧），ROI1缓冲区为空
- 代码进入"情况2: ROI1数据不足"
- **跳过所有波峰检测**（原始代码和重构代码都是这样）
- 导致 `peak_statistics.csv` 中没有数据

## 为什么export2有数据而export没有？

### 可能原因1: 配置不同

**export2使用的配置**（推测）:
```json
{
  "hybrid_detection": {
    "enabled": false  // ← 关键差异
  }
}
```

或者

```json
{
  "roi1_peak_detection": {
    "enabled": false  // ← 关键差异
  }
}
```

**验证方法**:
```bash
# 检查export2生成时使用的配置
# 或者查看export2的日志文件
```

### 可能原因2: 视频长度不同

**export2**:
- 可能处理的是视频的中间片段
- ROI1缓冲区已经有数据
- 能正常使用混合检测

**export**:
- 从视频开始处理
- ROI1缓冲区为空
- 跳过开始阶段的检测

### 可能原因3: 代码版本不同

**export2**:
- 可能使用的是旧版本代码
- 当时的逻辑不同

**export**:
- 使用重构后的代码
- 逻辑已经修复为与原始一致

## 如何让export有数据（3种方案）

### 方案1: 修改配置（推荐，与原始代码一致）

**原理**: 修改配置使代码进入"情况3: ROI2独立检测"

**操作**:
```json
// simple_fem_config.json
{
  "hybrid_detection": {
    "enabled": false  // 改为 false
  }
}
```

**效果**:
- ✅ 所有帧都会进行ROI2独立检测
- ✅ 与原始代码行为一致（使用相同配置）
- ✅ 立即开始检测，不会跳过任何帧
- ⚠️ 失去混合检测的优势（ROI1时机 + ROI2颜色）

### 方案2: 等待ROI1缓冲区满（与原始代码一致）

**原理**: 保持当前配置，等待100帧后自动使用混合检测

**操作**:
- 不修改任何配置
- 确保视频长度 > 100帧

**效果**:
- ✅ 0-99帧: 跳过检测（ROI1数据不足）
- ✅ 100帧以后: 使用混合检测
- ⚠️ 视频开始阶段的波峰会丢失

**适用场景**:
- 视频很长（>200帧）
- 主要关注视频后段的波峰
- 需要使用混合检测的高精度

### 方案3: 修改代码逻辑（与原始代码不一致）

**原理**: 在ROI1数据不足时回退到ROI2检测

**修改**: `refactor/orchestrator.py` 第350-357行

```python
elif hybrid_enabled and roi1_enabled:
    # 情况2: ROI1数据不足
    # 修改前: pass（跳过检测）
    # 修改后: 回退到ROI2检测
    green_peaks, red_peaks = detect_peaks(
        list(self._roi_capture.roi2_buffer),
        threshold,
        ...
    )
```

**效果**:
- ✅ 不会丢失任何波峰
- ❌ **与原始代码逻辑不一致**
- ❌ 原始代码在ROI1数据不足时也跳过检测

## 关键结论

1. **重构代码的逻辑已经与原始代码完全一致**
   - 三态波峰检测逻辑
   - ROI1数据不足时跳过检测
   - 混合检测结果传递

2. **当前没有波峰的原因**:
   - 配置启用了混合检测和ROI1检测
   - 视频开始阶段ROI1缓冲区为空

3. **export2有数据的可能原因**:
   - 使用了不同的配置（hybrid_detection.enabled=false）
   - 或者处理的不是视频开始阶段

4. **解决方案**:
   - 修改配置: `hybrid_detection.enabled = false`（推荐）
   - 或者等待ROI1缓冲区满后自动检测
   - 或者修改代码添加回退机制（会与原始不一致）
