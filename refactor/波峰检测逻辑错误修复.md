# 波峰检测逻辑错误修复文档

## 问题描述

重构后的代码在 `export/` 目录下生成的CSV结果与 `export2/` 目录下（原始代码生成）的结果不一致。

### 示例对比

**视频**: `2（5次发射，1无效）.mp4`

**export2（正确结果 - 原始代码）**:
```
- 波峰数量: 5个
- 颜色分布: 全部绿色
- 帧索引: 93, 400, 458, 548, 1091
```

**export（错误结果 - 重构代码）**:
```
- 波峰数量: 7个
- 颜色分布: 5绿色，2红色
- 帧索引: 254(red), 687(green), 885(green), 1066(green), 1286(red), 1431(green), 1729(green)
```

## 根本原因

### 重构代码的错误逻辑（orchestrator.py 第327-348行）

```python
# 6. 波峰检测（ROI2 + 混合检测）
green_peaks, red_peaks = detect_peaks(
    list(self._roi_capture.roi2_buffer),
    threshold,
    ...
)

# 混合检测（ROI1 检测波峰时机 + ROI2 判定颜色）
hybrid_green_peaks, hybrid_red_peaks, hybrid_info = self._hybrid_detection.detect_hybrid_peaks(...)

# 合并波峰结果
if self._config.hybrid_detection_enabled and len(hybrid_green_peaks) > 0:
    # 使用混合检测结果
    green_peaks = hybrid_green_peaks
    red_peaks = hybrid_red_peaks
```

**问题**: 第345行的条件 `len(hybrid_green_peaks) > 0` 导致：
1. 总是先对ROI2进行一次波峰检测
2. 然后调用混合检测
3. **只有当混合检测检测到至少一个绿色波峰时**，才用混合检测结果覆盖ROI2结果
4. 如果混合检测只检测到红色波峰，或者混合检测失败，就会使用ROI2的检测结果

### 原始代码的正确逻辑（simple_roi_daemon.py 第2260-2313行）

```python
if hybrid_enabled:
    # 混合检测（ROI1 检测波峰时机 + ROI2 判定颜色）
    hybrid_peaks = hybrid_peak_detection(...)
    # 转换为传统格式
    green_peaks = [p['peak_interval'] for p in hybrid_peaks if p['color'] == 'green']
    red_peaks = [p['peak_interval'] for p in hybrid_peaks if p['color'] == 'red']
else:
    # ROI2 独立检测（传统模式）
    green_peaks, red_peaks = detect_peaks(roi2_curve, ...)
```

**正确逻辑**:
- 如果混合检测启用 → **总是**使用混合检测结果（包括绿色和红色波峰）
- 如果混合检测未启用 → 使用ROI2独立检测

## 修复方案

### 修改 orchestrator.py 第326-350行

```python
# 6. 波峰检测（混合检测或ROI2独立检测）
green_peaks, red_peaks = [], []
hybrid_green_peaks, hybrid_red_peaks, hybrid_info = [], [], []

if self._config.hybrid_detection_enabled:
    # 混合检测（ROI1 检测波峰时机 + ROI2 判定颜色）
    hybrid_green_peaks, hybrid_red_peaks, hybrid_info = self._hybrid_detection.detect_hybrid_peaks(
        list(self._roi_capture.roi1_buffer),
        list(self._roi_capture.roi2_buffer),
        self._frame_index,
        intersection
    )
    # 使用混合检测结果（包括绿色和红色波峰）
    green_peaks = hybrid_green_peaks
    red_peaks = hybrid_red_peaks
else:
    # ROI2 独立检测（传统模式）
    green_peaks, red_peaks = detect_peaks(
        list(self._roi_capture.roi2_buffer),
        threshold,
        difference_threshold=self._config.difference_threshold,
        margin_frames=self._config.margin_frames,
        silence_frames=self._config.silence_frames,
        min_region_length=self._config.min_region_length
    )
```

### 关键改进

1. **互斥逻辑**: 混合检测和ROI2检测完全分开，不会同时执行
2. **无条件使用混合检测结果**: 移除了 `len(hybrid_green_peaks) > 0` 的条件限制
3. **清晰的代码结构**: if-else 结构使逻辑更明确

## 总结

这是一个经典的"重构引入逻辑错误"的案例：
- **重构前**: 清晰的 if-else 逻辑（要么混合检测，要么ROI2检测）
- **重构后**: 先执行ROI2检测，再根据条件覆盖，导致逻辑混乱
- **修复**: 恢复原始的互斥逻辑，确保混合检测和ROI2检测不会互相干扰

**教训**: 重构时不仅要关注代码结构，更要确保核心业务逻辑的正确性。
